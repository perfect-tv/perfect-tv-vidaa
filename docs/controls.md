# Управление и навигация

Эталон раскладки. Меняется раскладка — обновить этот файл и окно «Управление» (`src/ui/popups.c`, строки `S_HELP_*`
в `src/core/strings.def`). Источник — Android-версия; отличия для VIDAA отмечены.

## Клавиши пульта

События идут из `/dev/input/event*` (оболочка SDK открывает все узлы с клавишами навигации) в `raw_key` → `ui/keys.c`.
Один и тот же смысл приходит разными кодами на разных пультах — принимаются все.

| Коды evdev | Имя |
|---|---|
| 105 / 106 / 103 / 108 | ← → ↑ ↓ |
| 28 ENTER, 352 OK, 353 SELECT, 96 KPENTER | OK |
| 158 BACK, 1 ESC, 14 BACKSPACE | Назад |
| 102 HOME, 172 HOMEPAGE, 174 EXIT | Home — выход из приложения |
| 139 MENU, 127 COMPOSE | Меню |
| 402 CH+, 104 PageUp / 403 CH−, 109 PageDown | CH+ / CH− |
| 2…11, 512…521, цифровой блок | цифры |
| 164 PLAYPAUSE, 207 PLAY, 119/201 PAUSE, 128/166 STOP, 168 REWIND, 208 FASTFORWARD | ⏯ ▶ ⏸ ⏹ ⏪ ⏩ |
| 358 INFO, 365 EPG, 395/405 LIST/LAST, 364 FAVORITES, 388 TEXT, 370 SUBTITLE, 217 SEARCH | инфопанель, гид, недавние, избранное, телетекст, субтитры вкл/выкл, поиск |
| 398 / 399 / 400 / 401 | красная / зелёная / жёлтая / синяя |

Каждое нажатие пишется в журнал строкой `key code=N` — по журналу видно, что присылает необычный пульт.

**Пульт без цветных кнопок.** Все действия доступны стрелками, OK, «Назад», «Меню» и удержанием OK; цветные кнопки —
только ярлыки: красная — программа канала, зелёная — гид, жёлтая — избранное, синяя — инфопанель.

## Долгие нажатия и удержание

- Если у верхнего слоя для клавиши есть долгое действие, короткое срабатывает при отпускании, долгое — через 500 мс
  удержания (OK — 800 мс). После долгого повторы этой клавиши игнорируются до отпускания. Без долгого — сразу.
- Удержание ↑/↓ листает своим таймером: старт через 350 мс, шаг с ускорением от 90 до 35 мс за 1,5 с.
- ←/→ и CH± при удержании повторяются автоповтором пульта (перемотка, страницы). В окне PIN повторов нет.

## Плеер (нет открытых окон)

| Кнопка | Эфир | Архив |
|---|---|---|
| ← / → | предыдущий / следующий канал категории (задержка 0,7 с, инфопанель и карусель) | перемотка −/+: нажатие — 30 с, удержание — быстрее (до 10 мин эфира в секунду); применяется через 0,9 с |
| ↑ | раскрыто описание — свернуть; инфопанель на экране — закрыть; иначе «Программа и архив» (или «Недавние каналы» — настройка) | то же |
| ↓ | инфопанель закреплена; ещё раз — описание передачи | то же |
| OK | ТВ-гид; набирается номер — переключить; идёт перемотка — применить; инфопанель на экране — пауза / продолжить; канал недоступен — повторить | то же |
| удерж. OK, Меню | меню канала | то же |
| удерж. ↓ / удерж. ↑ | недавние каналы / напоминания | то же |
| CH+ / CH− | следующий / предыдущий канал | то же |
| 0–9 | номер канала: набранный номер, логотип и название, ниже — каналы, которые выберутся следующей цифрой; через 2 с или сразу, если следующая цифра невозможна | то же |
| ⏯ ▶ ⏸ | пауза / продолжить (эфир после паузы — со сдвигом через архив) | то же |
| ⏪ / ⏩ | перемотка: из эфира — в архив | перемотка |
| ⏹ | как «Назад» | в эфир |
| Назад | отмена номера / перемотки → свернуть описание → открепить инфопанель → тост «нажмите ещё раз»; второе «Назад» за 2 с — выход | то же |

**Назад ×2 на закрытом канале** — не выход: включается последний незаблокированный канал (тот, что играл перед
закрытыми, или первый незаблокированный из недавних), PIN снова нужен.

**Закрытые каналы при листании.** ←/→ попали на закрытый — окно PIN; отмена — следующий в ту же сторону без PIN. Из
закрытого, открытого по PIN, в другой закрытый — без PIN.

**Карусель.** При ←/→ и CH± над инфопанелью — лента логотипов категории, текущий по центру в белой рамке; скрывается через 1,5 с.

## ТВ-гид

Категории: «Избранное» (если не пусто), «Все каналы», категории плейлиста. Внизу — подсказки клавиш (настройка).

Выделенное название канала или передачи, которое не влезает в строку, прокручивается (настройка «Бегущая строка»:
пауза 1,5 с, 7 em/с, пауза, возврат); выключено — обрезается.

**Вид гида** (Настройки → Внешний вид → «Вид гида», в меню канала — «Вид»): «ТВ-гид» — сетка программы; «Каналы +
программа» — передачи канала в фокусе и даты; «Категории + каналы» — колонка категорий на экране всегда, программа
справа появляется по →; «Каналы» — только список каналов, справа видно видео, программа — по →. В трёх видах списка
с настройкой «Описание в ТВ-гиде» при переходе в программу каналы сжимаются до логотипов, справа выезжает панель
передачи (картинка, время, название, описание и что сделает OK).

**Фокус на каналах**

| Кнопка | Действие |
|---|---|
| ↑ / ↓ | канал (по кругу), удержание — быстро |
| CH± | на страницу (видимые строки без одной), до края списка |
| ← | колонка категорий |
| удерж. ← | «Программа и архив» канала (только в сетке) |
| → | сетка программы / список передач канала |
| OK | смотреть и закрыть гид |
| удерж. OK, Меню | меню канала |
| 0–9 | канал по номеру в категории |
| SEARCH | поиск (из любой зоны гида) |
| Назад | закрыть гид |

**Сетка** (окно 2 ч, шаг 30 мин, «сейчас» на 25 %; пока фокус на каналах — окно «живое»; на канале, который смотрят в
архиве, — янтарная линия кадра): ←/→ — передача (окно сдвигается), ↑/↓ — канал (время сохраняется), OK — карточка
передачи, Назад — к каналам.

Канал в фокусе списка — по центру, у краёв списка — без пустоты.

**Вид «Каналы + программа»**: каналы, передачи канала в фокусе (идущая — выше, со шкалой и рамкой LIVE; прошедшая в
архиве — значок архива, с напоминанием — часы) и колонка дат. В передачах: ↑/↓, CH± — передача; OK — идёт: эфир,
прошла и есть архив: из архива, иначе карточка; удерж. OK — карточка; ← / Назад — к каналам; → — даты. В датах:
↑/↓ — день (список сразу встаёт на идущую или первую передачу дня); ← / OK — к передачам, Назад — к каналам.

**Колонка категорий** (← из каналов): выезжает слева, каналы и сетка сдвигаются. ↑/↓ — категория (каналы меняются
сразу), CH± — на страницу, → / OK — к каналам; над категориями — строка «Поиск» (↑ с первой категории; OK — поиск,
↑ с неё — к последней категории), Назад — отмена (категория и канал — как были), ← — колонка плейлистов
(если их больше одного): ↑/↓ — плейлист, OK / → — открыть его, Назад — к категориям. Выбор другого плейлиста
не останавливает текущий канал: гид показывает каналы нового, видео играет прежнее; OK на канале переключает,
Назад из гида возвращает прежний плейлист.

## Программа и архив

↑ в плеере, удерж. ← в сетке, «Программа» в меню канала. Слева даты, в центре передачи, справа — панель передачи
(время, название, картинка, описание, что сделает OK). В шапке — «Программа» / «Напоминания · N».

| Кнопка | Действие |
|---|---|
| ↑ / ↓, CH± | передача |
| ← | к датам: ↑/↓ — день; → / OK / Назад — обратно (на идущую или первую передачу дня) |
| → | к кнопкам шапки: ← / → — соседняя (список меняется сразу), ↓ / OK / Назад — обратно |
| OK | прошла и в архиве — смотреть из архива; идёт — эфир; иначе — карточка |
| удерж. OK | карточка передачи |
| Назад | закрыть |

На вкладке «Напоминания»: ↑/↓ — напоминание, OK — удалить.

## Карточка передачи

←/→ — кнопки, ↑/↓ — прокрутка описания, OK — действие, Назад — закрыть. Кнопки: прошедшая в архиве — «Смотреть»;
идущая — «Смотреть с начала» (если есть архив) и «Смотреть эфир» (если этот канал сейчас в архиве) или «Смотреть»
(если другой); будущая — «Напомнить» / «Удалить напоминание».

## Меню канала

Шторка справа (видео и инфопанель видны). Сверху — до четырёх плиток: «Смотреть» (из гида или не текущий канал),
«В эфир» (идёт архив), «С начала» (есть архив и передача), «Программа», «В избранное» / «Из избранного», «Недавние»;
не поместившиеся — первыми пунктами «Просмотра».

- **Просмотр**: «О передаче», «Звуковая дорожка» (дорожек больше одной), «Формат кадра», «Телетекст» (есть в
  потоке), «Субтитры» › (есть в потоке), «Таймер сна».
- **Канал**: в «Избранном» — «Выше» / «Ниже»; «Скрыть канал»; «Заблокировать / Разблокировать канал» (первая
  блокировка — сначала задать PIN); «Категория «…»» › «Скрыть категорию», «Заблокировать / Разблокировать категорию».
- **Приложение**: «ТВ-гид» (из плеера), «Поиск», «Напоминания», «Список каналов» › («Вид», «Адаптивная сортировка», «Скрытое»),
  «Плейлист и программа» › («Плейлист» — если их несколько, «Обновить плейлист», «Обновить программу»), «Управление», «Настройки».

| Кнопка | Действие |
|---|---|
| ↑ / ↓ | пункт (по кругу, через ряд плиток) |
| ← / → | в ряду плиток — плитка; у пункта со значением — значение; у пункта с «›» → — страница; на странице ← — обратно |
| OK | выполнить; значения меняются на месте |
| Назад | со страницы — обратно, иначе закрыть |
| Меню | закрыть |

Не помещается (крупный размер интерфейса) — прокручивается к пункту в фокусе.

## Телетекст (кнопка TEXT, меню канала → «Телетекст»)

Как у Android-версии. Страница 40 × 25 в области 4:3 на всю высоту; по умолчанию — поверх видео (чёрный фон —
лёгкая вуаль, цветные почти непрозрачные, знаки с тенью), в меню — «Фон: чёрный». Пункты «Телетекст» и
«Субтитры» в меню канала есть, если поток несёт телетекст (поток через ретранслятор — известно сразу; напрямую —
неизвестно, пункты есть). Пока страниц нет — «Ждём телетекст…», дорожки нет — «В потоке нет телетекста» (или
«только субтитры DVB»), нет страницы — «Страница N ещё не пришла».

| Клавиатура | Действие |
|---|---|
| скрыта (по умолчанию) | ← / → — предыдущая / следующая из **принятых** страниц по кругу (ничего не принято — соседний номер); ↑ / ↓ — подстраницы; OK — показать клавиатуру; «Назад» — стереть набранное, затем закрыть |
| показана: ↑ / ↓ | ряд (по кругу из шести: `1 2 3`, `4 5 6`, `7 8 9`, `0 🔴 ⌫`, `🟢 🟡 🔵`, `‹ 100 ›`) |
| показана: ← / OK / → | левая / средняя / правая кнопка ряда: цифра, ссылка Fastext, стереть, предыдущая / индекс 100 / следующая страница |
| показана: «Назад» | стереть набранное, затем скрыть клавиатуру (настройка не меняется), затем закрыть |

Над клавиатурой — круг d-pad с кнопками текущего ряда, под ней — диапазоны принятых страниц (`100–109  116  888`,
текущий — белым). Всегда: цифры пульта — номер (три цифры, первая 1–8; вверху «P12-», через 4 с набор
сбрасывается), цветные — ссылки Fastext, CH± — подстраница вперёд / назад, TEXT — закрыть. Удерж. OK или «Меню» —
**меню телетекста**: «Клавиатура: показана / скрыта при открытии», «Фон: поверх видео / чёрный», «Скрытый текст»,
«Подстраницы: листаются / стоп» (сами — раз в 6 с; после ручного листания — пауза), «Закрыть телетекст».
Клавиатура и фон запоминаются. Мигающий текст мигает раз в 0,5 с. Страница субтитров (888 или объявленная)
показывается по времени кадра, обновляется раз в 0,25 с.

## Субтитры (меню канала → «Субтитры», кнопка SUBTITLE)

«Субтитры» в меню канала — список: «Выкл.» и дорожки потока: «Телетекст», «Французский · DVB · для
слабослышащих», «Русский · WebVTT», «Английский · TTML», «Английский · CC1», «Английский · CEA-708»… Показываем
телетекст, DVB (картинками), WebVTT и TTML / IMSC (текстовый) из HLS, закрытые субтитры CEA-608 / 708 из видео;
остальные
(mov_text, PGS…) видны в списке с «— не поддерживается». Пункт есть, если в потоке есть субтитры или они выбраны.
Выбор запоминается за каналом (по виду и языку — переживает перезапуск канала и смену дорожек местами). Кнопка
SUBTITLE: включены — выключить; выключены — включить запомненные или первые, что умеем показать (тост с названием).
Текст (телетекст, WebVTT, TTML) — строками на тёмных плашках над инфопанелью; DVB — картинками там, где их поставил
вещатель (экран вещателя растягивается на весь); CEA-608 / 708 — строками там, где их поставил вещатель (сетка 15
строк в безопасной зоне), цветом из потока. Всё — по времени кадра.

**Значки инфопанели** (как у Android-версии): «SUB» — в потоке есть субтитры (белый — включены), «TTX» —
телетекст. Через ретранслятор — по его разбору, напрямую — по дорожкам системного плеера.

## Поиск (меню канала → «Поиск», кнопка поиска на пульте — из плеера и гида)

Во весь экран. Слева — поле, клавиатура и «Запросы»; справа — результаты: «Каналы» (без скрытых; по названию — все
слова, или по номеру), «Сейчас в эфире», «Скоро» (неделя вперёд), «В архиве» (в пределах архива канала), по 30 в
разделе. Каналы ищутся сразу, передачи — по названию, через 0,3 с после набора, от двух букв (без учёта регистра,
ё = е). Время у находки: в эфире — «03:15 – 03:30» и значок «Эфир»; иначе день и время (в архиве — значок архива).

| Где фокус | Клавиша | Действие |
|---|---|---|
| Клавиатура | ← ↑ ↓ → | соседняя клавиша; → с правого края или «Готово» — результаты, ↓ с нижнего ряда — запросы, ↑ с верхнего — на месте |
| | OK, 0–9, CH+ | ввести / цифра / стереть; удерж. OK на ⌫ — очистить |
| | Назад | закрыть поиск |
| Запросы | ↑ / ↓ | запрос; ↑ с первого — клавиатура; → — результаты |
| | OK | подставить запрос |
| | удерж. OK | убрать недавний (у подсказок — ничего) |
| | Назад | к клавиатуре |
| Результаты | ↑ / ↓, CH± | находка (CH± — по 8) |
| | OK | канал или передача в эфире — смотреть; из архива — с её начала; будущая — карточка передачи («Напомнить») |
| | удерж. OK | «Программа и архив» канала |
| | ←, Назад | к клавиатуре |

«Запросы» — до пяти: недавние (часы; запоминается запрос, по находке которого нажали OK, до 8) — подходящие к
набранному, затем подсказки из найденных названий (лупа). Клавиша, с которой фокус ушёл из клавиатуры, — в рамке.

## Недавние каналы

↑/↓ — канал, OK — смотреть, удерж. OK или Меню — меню канала, Назад — закрыть.

## Напоминания

Окно справа сверху, когда до начала передачи осталось «Напоминать о передаче» минут: канал, «Напоминание · через N
минут» / «уже идёт», название; кнопки «Смотреть» (в фокусе), «Отложить на 5 мин», «Закрыть», при нескольких — «Закрыть
все» и счётчик «1 / 3» (↑/↓ — другие). Пропущенная передача с архивом — один раз «Пропущено»: «Смотреть из архива»,
«Позже» (остаётся в списке), «Удалить». Под названием — описание передачи, если оно было в программе. Пропущенная без архива удаляется. Напоминания из другого плейлиста видны и
там: глубина архива записана в напоминании, «Смотреть» переключает плейлист и открывает канал (если его каналы уже
загружены). Напоминания работают, только пока приложение открыто (системных уведомлений у нативного приложения нет).

## Окно PIN

PIN — 4–6 цифр, видны только точки. Цифры пульта работают всегда, «Назад» стирает цифру, на пустом — отмена. Верный
PIN принимается сразу; 6 цифр без совпадения — «Неверный PIN». Способ ввода — настройка:

- **Кольцо**: ↑ → ↓ ← = 1 2 3 4, OK = 0; «Меню» или удерж. OK — раскладка 5–9 (↑ → ↓ ← = 5 6 7 8, OK = 9).
- **Ряды**: ←/OK/→ — левая/средняя/правая цифра ряда, ↑/↓ — ряд (с 1·2·3 вверх — на 7·8·9), на ряду 7·8·9 ↓ = 0.
- **Клавиатура**: 1–9, ⌫, 0, стрелки по кнопкам.

Новый PIN — всегда клавиатурой с «Готово» (✓), дважды.

## Настройки

В разделах: ↑/↓ — раздел (пункты справа меняются сразу), → / OK — к пунктам, Назад — выйти. В пунктах: ↑/↓ — пункт,
CH± — на 8, ← / → — предыдущее / следующее значение (у пункта без значений ← — к разделам), OK — следующее значение или
действие, Назад — к разделам.

## Просмотр (Настройки → Просмотр)

Дорожки и оформление субтитров: «Размер субтитров» (75–200 %), «Цвет субтитров» (как в потоке / белый / жёлтый /
зелёный / голубой), «Фон субтитров» (нет / полупрозрачный / чёрный), «Обводка субтитров» (нет / контур / тень),
«Отступ субтитров снизу» (0–18 % высоты экрана). Выбранные звуковая дорожка и субтитры запоминаются и
предпочитаются на других каналах; DVB-субтитры рисуются вещателем и оформление не меняют.

## Плейлисты (Настройки → Плейлисты)

↑/↓ — плейлист, OK — форма; ←/→ на строке плейлиста — переместить его выше/ниже (порядок сохраняется).
Выбор другого плейлиста из гида не останавливает текущий канал (см. «ТВ-гид»).

## Описания TMDB (Настройки → Описания (TMDB))

Пункты: «Ключ API (v3) или токен (v4)» (OK — клавиатура), «Ввести с телефона (QR)», «Адрес API», «Адрес картинок»
(OK — клавиатура; стандартный адрес хранится пустым), «Проверить» (тост с результатом), «Удалить ключ» (с
подтверждением). С ключом в раскрытой инфопанели (↓↓ в плеере) — картинка, год и рейтинг TMDB, описание (если в
программе его нет).

## Сеть (Настройки → Сеть)

«Поток через приложение» (Вкл/Выкл; действует со следующего открытия канала), «Каналы с прямым подключением» (есть,
если такие каналы появились: число, OK — снова пробовать их через приложение), «Принимать любые сертификаты».

## Резервная копия (Настройки → Данные)

«Очистить кэш логотипов» — память и папка `logos` в данных; логотипы скачаются снова при показе.
«Сохранить резервную копию» — сразу, тост с путём. «Восстановить из копии» — список копий (↑/↓, OK), подтверждение
(«Отмена» в фокусе, → «Восстановить»), при заданном PIN — окно PIN; затем приложение начинает заново с данными копии.
«Диагностика» — сводка для ТВ: версия, папка данных, плейлисты/каналы, источники и прогресс программы,
плеер и кодеки, ретранслятор, свободное место и путь журнала; ↑/↓ — прокрутка, Назад — закрыть.

## О программе (Настройки → О программе)

«Perfect TV» — версия и описание; «Телеграм-канал», «Поддержать проект», «Исходный код» — OK открывает окно с
QR-кодом и адресом (наводят камеру телефона; OK / Назад — закрыть). Адреса — как у Android-версии
(`t.me/perfect_tv_app`, `boosty.to/rootu/donate`), исходный код — репозиторий этого приложения. «Лицензия» — окно
с текстом (GNU GPL 3.0, библиотеки, TMDB, товарные знаки).

## Формы и клавиатура

Раскладка — настройка «Внешний вид → Раскладка клавиатуры»: стандартная (ЙЦУКЕН / QWERTY) или по алфавиту
(как в Android: три строки по 11 букв). Цифры, символы и служебный ряд не меняются.

Кнопки формы плейлиста: «Сохранить», «С телефона (QR)», «С флешки», «Удалить» (у существующего), «Отмена».
Окно «Файл с флешки»: накопители (один — сразу его корень), папки и файлы `.m3u .m3u8 .txt .gz .zip .xml .xmltv`;
↑/↓, CH± — пункт; OK / → — войти в папку или выбрать файл; ← / Назад — папка выше (из корня — к накопителям или
закрыть). Плейлист — в «Адрес» (название по умолчанию — имя файла без расширения); файл программы (`.xml`,
`.xml.gz`, `.xmltv`) — в свои источники, режим «из плейлиста» → «плейлист + свои». Окно «Ввод с
телефона»: QR-код и адрес страницы; ответ с телефона закрывает окно и заполняет форму; срок истёк — OK, новый код;
Назад — закрыть. В мастере — те же «Добавить плейлист», «С телефона (QR)», «Выход» (← → ↑ ↓ — кнопка).

Форма плейлиста: ↑/↓ — поле, OK — изменить (клавиатура), у «Программа (EPG)» ← / → / OK — режим, внизу — кнопки
(← / → и OK). Клавиатура: стрелки — клавиша (по кругу), OK — ввести, удерж. OK на ⌫ — очистить, CH+ — стереть,
цифры пульта — цифры, «Готово» — принять, Назад — отмена.
