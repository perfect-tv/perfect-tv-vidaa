# Перенос Android-версии в VIDAA: что осталось

Сверка Android-версии (`/home/putilin/Project/perfecttv`, состояние на 2026-11-19) и нативной VIDAA.
Основание — `docs/TZ.md`, `docs/PLAN.md`, `docs/controls.md` Android и `src/` обеих версий.

**P0** — потеря данных или заведомо неверное поведение. **P1** — заметная функция/поведение Android.
**P2** — мелочи и отложенные улучшения. **Не переносится** — ограничение платформы или SDK.

## P0: сначала исправить

- [x] **P0.1. Удаление плейлиста не оставляет его данные.**
      `repo_delete_playlist()` (`src/data/repo.c:102-115`) удаляет только `channels_<id>.tsv`;
      `fav.<id>`, `hist.<id>`, `hidc.<id>`, `hidg.<id>`, `lockc.<id>`, `lockg.<id>`, `score.<id>`
      остаются, а `repo_add_playlist()` (`:85-99`) может выдать тот же id. Новый плейлист наследует
      чужое избранное, скрытое, замки и очки. Удалять ключи, напоминания этого плейлиста,
      `last_playlist/last_channel/last_group` — если они указывали на удалённый.
      Критерий: удалили единственный плейлист, добавили новый — он чистый.

- [x] **P0.2. Архив на программном плеере не играет «с начала».**
      `src/player/player.c:62-66`: `swp_open()` не принимает `start`; у `swp` нет `seek`/`position`
      (`vendor/sw_player.h`). Сейчас архив на MPEG-2/MP2 молча открывается с начала ссылки, а пауза
      и перемотка не работают. В P0 — не открывать архив программным плеером и показать причину;
      полноценный seek — только если появится API в `vendor/` (см. «Не переносится»).
      Критерий: при отказе HMC на архивной ссылке — экран ошибки, а не неверный участок.

- [x] **P0.3. Режим EPG и свои источники сохраняются сразу.**
      `src/ui/form.c:191` меняет `PF.epg_mode`, но `playlists.json` пишется только в `save()`.
      «Назад» после смены режима теряет выбор. Сохранять режим при переключении (для существующего
      плейлиста), как в Android.
      Критерий: сменили режим, вышли «Назад», открыли форму снова — режим прежний.

- [x] **P0.4. Запасной логотип.**
      `src/data/repo.c:727-731` отдаёт только первый адрес по приоритету; `d_logo()`
      (`src/ui/u.c:484-500`) при ошибке сразу рисует монограмму. Пробовать второй источник
      (плейлист ↔ программа), как в `Logos.kt`.
      Критерий: первый адрес отдаёт 404 — показывается логотип из второго источника.

- [x] **P0.5. Напоминание чужого плейлиста не открывает чужой канал.**
      `src/ui/popups.c:339-342`: обе ветки тернарника ищут канал в текущем плейлисте, поэтому
      напоминание из другого плейлиста может открыть одноимённый канал или удалиться как
      «пропущенное без архива» (`:426-433`). В P0 — не разрешать канал из другого плейлиста и не
      удалять такие напоминания; полноценный переход к плейлисту — P1.
      Критерий: напоминание другого плейлиста остаётся в списке и не запускает чужой канал.

## P1: перенести поведение и функции

- [x] **Смена плейлиста без прерывания просмотра.** Android: видео играет, гид показывает каналы
      нового плейлиста, переключение — по OK, «Назад» возвращает прежний. Native сейчас сразу
      переключает канал (`src/ui/menu.c:142-152`, `src/ui/guide.c:193-204`, `src/ui/tv.c:501-529`).
      Нужен снимок играющего канала или отдельный «предпросмотр» плейлиста; это переделка модели
      `R`/`T.cur`, не косметика.
- [x] **Напоминания другого плейлиста:** глубина архива хранится в напоминании (`archive_days`), поэтому
      пропущенное показывается и без загруженного канала; «Смотреть» переключает плейлист и открывает
      эфир/архив, если файл каналов уже есть; если файла нет — тост и напоминание остаётся.
- [x] **Оформление субтитров:** размер, цвет, фон, контур/тень, отступ снизу
      (`SubtitleStyle.kt`, `Prefs.sub*`). Native: `src/ui/subs.c:251-263` — жёсткие 1,9 em, белый,
      плашка. Для DVB-картинок не применяется.
- [x] **Предпочитаемый язык звука и субтитров:** `Prefs.audioLang/subtitleLang` в Android;
      native хранит выбор субтитров только за каналом, звук сбрасывается.
- [x] **«Скрытое» и сброс очков для всех плейлистов.** Сейчас `hidc.<id>`/`score.<id>` только
      текущего (`src/data/repo.c:149-152, 844-850`).
- [x] **Четыре вида гида** («ТВ-гид», «Каналы + программа», «Категории + каналы», «Каналы»)
      и настройка «Описание в ТВ-гиде»: в видах списка каналы сжимаются до логотипов, справа панель передачи.
- [x] **Бегущая строка** выделенных длинных названий (каналы, передачи, шапка, инфопанель); Настройки →
      Внешний вид; кадры запрашиваются только пока что-то едет.
- [x] **Сторож зависания видео.** «Позиция не растёт 20 с» → ошибка и повтор.
- [x] **Диагностика:** «Настройки → Данные → Диагностика» — версия, папка данных, плейлисты/каналы,
      источники и прогресс программы, плеер/кодеки/позиция, ретранслятор, свободное место и путь журнала.
- [x] **Порядок плейлистов** («Выше/Ниже»): `repo_move_playlist()` уже есть, пункта нет.
- [x] **Кэш логотипов на диске:** `data_dir/logos` (до 64 МБ, старые выгрузки чистятся), в памяти LRU
      12 МБ; неудачный адрес не запрашивается до очистки; «Очистить кэш логотипов» чистит память и диск.

## Не переносится / ограничено SDK

- **Выбор видеодорожки:** `vendor/player-hmc.h` отдаёт только аудио/субтитры; API видео-дорожек нет.
- **Деинтерлейсинг, выбор видеодекодера:** кадры HMC идут прямо на плоскость ТВ, шейдер не вставить.
- **Аудиодорожка другого формата:** ограничение ES-режима HMC; `vendor/` не правится.
- **DASH/PGS/mov_text:** только если появятся демуксер/рендер в SDK.
- ** Архив на программном плеере с seek/паузой:** `sw_player` не имеет позиции и seek; P0 только
  запрещает неверное воспроизведение.
- **Тач, мышь, жесты:** у VIDAA-ТВ пульт evdev.
- **Голосовой ввод:** нет распознавания речи в нативном SDK.
- **Главный экран Android TV** (ряды, баннеры, deep link, голосовой запуск): нет API лаунчера.
- **Системные уведомления напоминаний:** в VIDAA их нет.
- **Автообновление APK с GitHub, подпись/релизный workflow:** обновление через кабинет автора.
- **LeakCanary, MediaStore, открытие `*.perfecttv` из файлового менеджера:** Android-специфика.
- **Плавные анимации слоёв:** в native сознательно не делались (слабый ТВ); можно оставить.
