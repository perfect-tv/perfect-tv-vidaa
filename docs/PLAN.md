# План и что проверено

Пометки: **ТВ** — проверено на телевизоре; **ПК** — проверено на ПК (юнит-тесты или запуск интерфейса с заглушкой
плеера, снимки экрана); **сборка** — только собирается. Ни одна функция пока не помечена **ТВ**.

## Первым делом на ТВ

1. Запуск с плитки, журнал `.startup.log`: `lifecycle_init_result`, `display_layer`, `inputs`, `playlists=`.
2. Пульт: все кнопки (журнал `key code=`), удержание OK / ↓ / ↑, повтор ←/→ (перемотка), пульт без цветных кнопок.
3. **Полупрозрачность поверх видео**: видно ли видео под затемнением инфопанели, гида (97→80 %) и меню. Если окно
   DirectFB не смешивает частичную прозрачность — сделать «облегчённый интерфейс» без прозрачности (как у веб-версии:
   сплошные панели) и, возможно, гид непрозрачным.
4. Плейлист по https провайдера, программа на сотни мегабайт: время разбора (на ПК — ~40 МБ/с XML вместе со
   сжатием), память, место на диске (`epg/`), отзывчивость во время загрузки; листание гида — чтение кусков с флеш-памяти.
5. Каналы HLS и MPEG-TS; MPEG-2 / MP2 (программный плеер: нагрузка); заголовки User-Agent / Referer.
6. Архив: Flussonic (окно `archive-START-DURATION`), shift (`?utc=`), xc; перемотка внутри окна и за ним; конец окна.
7. Выход «Назад» ×2 и Home — Home без чёрного экрана, плеер закрыт; повторный запуск.
8. Скорость кадра: листание гида с удержанием ↑/↓ на слабом ТВ (полная перерисовка 1920×1080 на ARM).
9. Ввод с телефона: открывается ли порт 47381 из сети (брандмауэр ТВ), какой адрес выбран (Wi-Fi / Ethernet),
   читает ли QR камера телефона с 2–3 м.
10. Каталог данных при запуске от uid 301 (проектор): настройки и программа сохраняются.

## Не сделано (есть в Android-версии)

- Телетекст (DVB, страницы и субтитры) — нужен доступ к PES телетекста; `vendor/player-hmc.c` дорожки отбрасывает.
- Субтитры и их оформление; выбор дорожки звука другого формата (ограничение режима ES системного плеера).
- Поиск по каналам и программе, голосовой ввод.
- Описания TMDB.
- Резервная копия и восстановление.
- Автообновление (GitHub releases) — для магазина VIDAA не нужно: обновление через кабинет автора.
- Выбор файла плейлиста из списка (USB): сейчас — путь вручную (`/mnt/usb/…`, точные пути VIDAA не выяснены).
- Главный экран ТВ, системные уведомления напоминаний (у нативного приложения их нет).
- Деинтерлейсинг, выбор видеодекодера, сторож зависания (системный плеер ТВ решает сам).
- Плавные анимации появления слоёв.
- Перетаскивание порядка плейлистов (`repo_move_playlist` есть, пункта нет).

## Решения, принятые при переносе

- Хранение без SQLite: настройки — JSON каркаса, каналы — TSV, программа — сжатые куски «канал + сутки» с
  оглавлением по корзинам, без `mmap` (§3 ТЗ: 2 ГБ XMLTV не помещаются в адресное пространство ARM32).
- Flussonic: только `archive-START-DURATION` (FFmpeg начинает EVENT у края; опций демуксеру через `vendor/` не передать).
- Пауза эфира: без DVR-окна HLS (FFmpeg его не держит) — архивная ссылка с момента паузы.
- Язык по умолчанию — русский (переменных окружения LANG на ТВ нет).
- Своя экранная клавиатура (у VIDAA нет системной для нативных приложений).
