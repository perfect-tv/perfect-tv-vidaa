# Perfect TV для VIDAA (нативное приложение)

IPTV-плеер Perfect TV для телевизоров Hisense / Toshiba на VIDAA OS — **нативное приложение на C** (DirectFB, без браузера).
Порт [Android-версии](https://github.com/perfect-tv) (эталон поведения) и веб-версии для webOS / Tizen / VIDAA-браузера:
тот же разбор плейлиста и программы, ТВ-гид, архив, PIN, избранное — на каркасе нативного SDK VIDAA.

> **Статус: собирается, на ТВ не запускалось.** Всё проверено юнит-тестами и запуском интерфейса на ПК с заглушкой
> плеера (снимки экрана). Оболочка ТВ (`fw/tv_shell.c` SDK) и плееры (`vendor/`) — проверенные на ТВ куски SDK, но
> само приложение на телевизоре ещё не ставилось: см. «Первый запуск на ТВ» и `docs/PLAN.md`.

## Что умеет

- Плейлисты M3U/M3U8 по адресу (http, https) или из файла (`/путь` или `file://`), gzip и zip, потоковый разбор;
  несколько плейлистов, свои источники программы и режим «из плейлиста / плейлист + свои / только свои».
- Программа XMLTV (gzip, zip; UTF-8, windows-1251, koi8-r) — свой потоковый разборщик, фильтр по каналам плейлиста
  и окну хранения; хранилище — куски «канал + сутки» со сжатием и оглавлением по корзинам, читается кусками (2 ГБ XML
  — несколько мегабайт памяти); источник общий для плейлистов; прошлое (архив) переносится в новую выгрузку.
- Сопоставление каналов с программой: `tvg-id`, `tvg-name`, имя с нормализацией и транслитом.
- Эфир и архив (catchup: shift / append / default / flussonic / xc, все подстановки `${…}`), перемотка с ускорением,
  пауза эфира со сдвигом через архив, продолжение архива по следующей передаче, переход в эфир.
- Инфопанель (бейджи, шкала, «Далее», раскрытое описание), карусель каналов, набор номера с подсказками.
- ТВ-гид: сетка (2 ч, «сейчас» на 25 %) и «Каналы + программа» с датами; колонки категорий и плейлистов.
- «Программа и архив», карточка передачи, напоминания (окно со счётчиком, «Отложить», пропущенное — из архива).
- Меню канала (плитки, звук, формат кадра, таймер сна, скрыть, заблокировать, категория, список, плейлист).
- Избранное, недавние, скрытые каналы и категории, адаптивная сортировка, блокировка по PIN (кольцо / ряды / клавиатура).
- Настройки в два столбца, экранная клавиатура (RU / EN / символы с кусками адресов), язык RU / EN на ходу.
- Системный плеер ТВ (HMC, видео «дырой» под интерфейсом) и программный запасной для MPEG-2 / MP2.

Чего пока нет (есть в Android-версии): телетекст, субтитры, голосовой поиск, TMDB, автообновление,
главный экран ТВ. Подробно — `docs/PLAN.md`.

## Сборка

Нужен **SDK нативных приложений VIDAA** (папка `native_app`: каркас `fw/`, `vendor/`, библиотеки ARM32 `prefix/`,
`runtime-libs/`, заголовки DirectFB, шрифты). По умолчанию ищется рядом: `../native_app`; иначе — `VIDAA_SDK=/путь`.
Из SDK в этот репозиторий ничего не копируется: чужой код `vendor/` и библиотеки остаются в SDK.

### Linux / macOS

Нужны Python 3.8+ и zig 0.13.0 (единственное, что нужно скачать: `zig-linux-x86_64-0.13.0` с ziglang.org
в `native_app/toolchain/`, или путь в `ZIG`).

```bash
python3 tools/build.py            # build/arm/perfecttv-app (ELF ARM32, glibc ≤ 2.28)
python3 tools/pack.py             # build/arm/tv.rootu.perfecttv.ipk (не подписан)
```

Версия — из git-тега `v1.2.3` (иначе `version` из `app.json`); `--version` у `pack.py` её переопределяет.
Пакет подписывает и публикует набор автора SDK (`native_app/publish`, `node vidaapp-author.cjs sign --ipk …`).

### Windows

Скрипты SDK понимают `app.json` этого репозитория: `scripts\build.ps1 -App <путь>` и `scripts\pack.ps1 -App <путь>`.
Они не знают о версии из git-тега и о `-DPTV_VERSION` — версия тогда «dev» в окне «О программе».

### AppId и имя пакета

`appId` (`99009990`) и `package` (`tv.rootu.perfecttv`) в `app.json` — **заглушки**. Их выдаёт сертификат автора
магазина VIDAA; чужой AppId перезапишет установленное приложение. Перед публикацией заменить на свои
(или `python3 tools/pack.py --app-id N --package tv.x.y`). `registerName` (`PerfectTVNative`) должен совпадать
со строкой в `src/main.c`.

## Проверка на ПК

Интерфейс собирается и под ПК (gcc, FreeType, zlib, OpenSSL из системы): тот же код экранов, плеер — заглушка
(«видео» — тестовая картинка под «дырой» холста), клавиши — по сценарию, кадры — в PPM.

```bash
python3 tools/build.py --tests    # юнит-тесты: M3U, XMLTV, распаковка, архив, имена, хранилище программы, строки
python3 tools/build.py --host     # build/host/perfecttv-host
python3 tools/make_demo.py build/host/demo     # демо-плейлист и программа вокруг текущего времени
```

Добавить демо-плейлист можно через мастер (адрес — путь к `demo.m3u`) или сразу файлом
`build/host/data/playlists.json`:

```json
[{"id":1,"name":"Демо","url":"/полный/путь/build/host/demo/demo.m3u","epg_mode":0}]
```

```bash
build/host/perfecttv-host wait:3 shot:live key:down shot:info key:ok shot:guide key:right shot:grid open:settings shot:settings
```

Шаги сценария: `key:ИМЯ`, `long:ИМЯ` (удержание 1 с), `hold:ИМЯ:СЕК`, `wait:СЕК`, `shot:ИМЯ`, `open:settings|guide|schedule|recent|menu`,
`lang:ru|en`. Клавиши: `left right up down ok back menu info guide chup chdown red green yellow blue play stop rew ff 0…9`.
Снимки — `build/host/shots/*.ppm`. В адресе канала «fail» — ошибка открытия, «sw» — программный плеер.

## Первый запуск на ТВ

1. Собрать, упаковать, подписать (AppId и пакет — из своего сертификата), поставить из кабинета магазина.
   Только что установленное приложение до перезагрузки ТВ может не стартовать (`start_fail_timeout 701`).
2. Журнал: `/APPS/pkgs/<пакет>/.startup.log` (или `/tmp/perfecttv-native.log`). Смотреть сначала:
   `lifecycle_init_result`, `display_layer`, `inputs=N`, `key code=…`, `playlists=… channels=…`, `playlist_load`,
   `epg_build`, `epg_load`, `player=software`, `crash_signal` (тогда `scripts/crash-lookup.ps1` SDK по `build/arm/perfecttv-app`).
3. Проверить: запуск с плитки, «Назад» ×2 и Home возвращают в Home без чёрного экрана, пульт (в том числе без цветных
   кнопок), плейлист по https, канал HLS и MPEG-TS, архив, смена канала и выход закрывают плеер.
4. Полупрозрачные затемнения поверх видео (инфопанель, гид, меню) рассчитаны на поканальную прозрачность окна
   DirectFB. Если на ТВ под ними чёрное — записать в `docs/PLAN.md` и сделать панели непрозрачными.

## Устройство

| Путь | Что |
|---|---|
| `src/main.c` | точка входа: оболочка ТВ SDK (`tv_shell_run`), сырые клавиши, выключение плеера |
| `src/core/` | строки RU/EN (`strings.def`), настройки, время с поправкой по серверу, потоковый HTTP(S), распаковка |
| `src/data/` | M3U, XMLTV, имена, шаблоны архива, хранилище программы, плейлисты и каналы, фоновые загрузки |
| `src/player/` | обёртка системного и программного плееров SDK: открытие в рабочем потоке, слияние переключений |
| `src/ui/` | экран ТВ, инфопанель, гид, программа, меню, окна, PIN, настройки, формы и клавиатура; отрисовка `u.c` |
| `host/` | запуск на ПК: заглушка плееров, сценарий клавиш, снимки |
| `tests/` | юнит-тесты (ПК) |
| `tools/` | `build.py`, `pack.py`, `make_demo.py` |
| `docs/` | ТЗ, управление, оформление, план |

Данные на ТВ — каталог данных из стартового скрипта (`PTV_DATA_DIR`, иначе `data/` рядом с программой): `settings.json`,
`playlists.json`, `channels_<id>.tsv`, `epg/<хэш>/` (программа источника), `reminders.json`.
